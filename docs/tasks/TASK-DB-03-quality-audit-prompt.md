## 二、任务 A：200 条逐条质量审计（覆盖 100%，零抽样）

对 `/tmp/tuna-feed-run/edited/tuna-feed-200.json` 的 200 条 `posts[]` 逐条判定，输出审计表：

| 字段 | 要求 |
|---|---|
| index / title（前 60 字） | 定位 |
| 类别 | `AI核心`（模型/Agent/推理/训练/基准/端侧…）/ `AI应用`（落地/产品/政策）/ `AI周边`（泛科技提及 AI）/ `无关`（与 AI 从业者决策无涉） |
| 质量分 0-10 | 以「对 AI 从业者的决策价值」为唯一标尺（10=必读，0=垃圾） |
| 判据一句话 | 每条一句（禁止只给分数不给理由） |
| 处置建议 | 保留 / 降权 / 剔除 |

汇总统计：类别分布、质量分直方图、**剔除清单**（质量分 <5 或类别=无关 的完整列表）、「若按你的标准重构，200 条里真正合格的条数」。

目标重述（老张的原话标准）：**「最优质、最适合用户需求的内容」，高维度宏观视角的质量检查，发挥 AI 潜能**。

设计要求：
1. **采集聚焦策略**：六渠道各自的白名单化方案（查询词组/源清单/节点过滤），确保「渠道 ≥50 条」不再与质量冲突（或明确建议取消该指标）；
